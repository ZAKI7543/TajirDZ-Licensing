# سجل تراخيص TajirDZ المركزي

هذا المستودع **مصدر الحقيقة الوحيد** لحالة تراخيص TajirDZ.

كل سجل ترخيص وكل حالة ربط جهاز **موقّع تشفيريًا (Ed25519)** — أي ملف بلا توقيع موثوق **غير صالح ويُرفض** من البرنامج. المسارات حتمية ثابتة لا تتحرك بتغير الحالة:

- `registry/licenses/<shard>/<licenseId>/license.json` — الـshard مشتق من هاش المفتاح
- `registry/index/<shard>.json` — (hash→licenseId) بحث حتمي · `registry/index/by-id/<licenseId>.json`
- `registry/device-bindings/<shard>/<licenseId>/<bindingId>.json`

لا يحتوي المستودع **أي أسرار أو مفاتيح خاصة أو بيانات شخصية** — بيانات تقنية موقعة فقط. ثقة العميل مثبتة بمفتاح داخل البناء الرسمي لا بهذا المستودع.

العمليات الإدارية: أداة سطر الأوامر الخاصة بالمالك (خارج بناء العميل).
